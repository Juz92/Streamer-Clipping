# Triage Labels

| Canonical role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Waiting for information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready |
| `ready-for-human` | `ready-for-human` | Requires human action |
| `wontfix` | `wontfix` | Will not be actioned |

Use the local status verbatim in each ticket's `Status:` line.
